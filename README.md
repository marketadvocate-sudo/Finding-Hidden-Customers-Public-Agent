# Finding Hidden Customers Agent

By Cannonball GTM. This agent identifies pain-based and demand-based market segments from publicly available compliance data — the buyers your competitors can't see.

## Deploy Your Own Instance

Click the button below to deploy your own private copy of the agent. You will need:

1. A Railway account (free to create)
2. An Anthropic API key (instructions below)
3. A password you choose (to protect your instance)

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/YOUR-TEMPLATE-ID)

## Getting an Anthropic API Key

1. Go to https://console.anthropic.com
2. Sign up or log in
3. Click "Get API Keys" in the left menu
4. Click "Create Key"
5. Copy the key immediately (it starts with sk-ant-) — you only see it once
6. Add credits to your account under "Billing" (start with $20)

Each brand analysis costs roughly $3 in API usage.

## Using the Agent

Once deployed, open your Railway URL. Enter your password. Then:

1. Enter a brand name or URL
2. Confirm the brand profile
3. Provide context about the company
4. Walk through each stage of the analysis
5. Generate a shareable report or GTM engineer recipe
